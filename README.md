🎬 IMDb Movie Data Analysis

📌 Project Overview

This project explores IMDb movie data using Python to understand movie trends, ratings, genres, revenue and other movie-related information.

🎯 Project Objective

To perform data analysis on IMDb movie records and discover useful insights through data manipulation and visualization.

🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

📊 Dataset Information

The dataset contains 1,000 movie records and 12 columns, including:

- Movie Title
- Genre
- Director
- Actors
- Release Year
- Runtime
- IMDb Rating
- Votes
- Revenue
- Metascore

🔍 Project Workflow

1. Import required Python libraries.
2. Load the IMDb dataset using Pandas.
3. Explore the dataset using "head()" and other DataFrame operations.
4. Analyze movie information and trends.
5. Use Matplotlib and Seaborn for data visualization.
